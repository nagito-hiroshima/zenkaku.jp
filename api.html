全角変換 公開API

zenkaku.jpの変換機能を、Webサイト・アプリ・自動処理から利用できます。APIキーは不要です。

エンドポイント

GET https://zenkaku.jp/api/convert?text=変換する文字列 POST https://zenkaku.jp/api/convert
  • ASCII英数字・記号と半角スペースを全角へ変換します。
  • 日本語やすでに全角になっている文字は、そのまま返します。
  • 入力上限はUTF-8で20,000バイトです。
  • レスポンス形式はJSON、文字コードはUTF-8です。
  • CORSに対応しているため、ブラウザのJavaScriptからも呼び出せます。

利用方法

GET（手軽な呼び出し）

curl --get 'https://zenkaku.jp/api/convert' \
  --data-urlencode 'text=Hello 123!'

POST（JSON・推奨）

curl 'https://zenkaku.jp/api/convert' \
  -H 'Content-Type: application/json' \
  --data '{"text":"Hello 123!"}'

JavaScript

const response = await fetch('https://zenkaku.jp/api/convert', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ text: 'Hello 123!' })
});

const data = await response.json();
console.log(data.result); // Ｈｅｌｌｏ　１２３！

Python

import requests

response = requests.post(
    'https://zenkaku.jp/api/convert',
    json={'text': 'Hello 123!'}
)
response.raise_for_status()
print(response.json()['result'])

レスポンス

成功時

{
  "success": true,
  "result": "Ｈｅｌｌｏ　１２３！",
  "input": {
    "characters": 10,
    "bytes": 10
  }
}

エラー時

{
  "success": false,
  "error": {
    "code": "MISSING_TEXT",
    "message": "クエリパラメータ \"text\" を指定してください。"
  }
}

主なHTTPステータス

ステータス内容
200変換成功
400入力不足またはJSON形式エラー
405未対応のHTTPメソッド
413入力上限を超過
415未対応のContent-Type
500サーバー内部エラー

利用ルール

  • 個人利用・商用利用のどちらでも利用できます。
  • APIキーおよび利用申請は不要です。
  • サービスへ過度な負荷を与える大量・連続アクセスは禁止します。必要に応じてアクセスを制限または遮断する場合があります。
  • 違法行為、攻撃、迷惑行為、第三者の権利侵害を目的とした利用は禁止します。
  • API自体を自分のサービスとして再販売する行為は禁止します。
  • 可用性や変換結果を保証するSLAはありません。保守などにより予告なく停止する場合があります。
  • 仕様・入力上限・利用ルールは、運用上必要な場合に変更されることがあります。

プライバシーと安全な利用

パスワード、APIキー、個人情報、秘密情報などは送信しないでください。GETでは入力文字列がURLに含まれるため、通常はPOSTの利用をおすすめします。

不正利用対策や障害調査のため、アクセス情報がホスティング事業者のログに記録される場合があります。
